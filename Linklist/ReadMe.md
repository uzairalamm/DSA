# Linked List

This folder contains my practice and implementations of **Linked Lists in C++** as part of my Data Structures and Algorithms learning.

### Topics Covered

- Singly Linked List
- Node creation and traversal
- Insertion
- Deletion
- Searching
- Head and tail pointers
- Dynamic memory allocation
- Linked List vs Array
- Time and space complexity

### Language

**C++**

### Purpose

The goal of this section is to build a strong understanding of linked lists through implementation and practice, rather than just learning the concepts theoretically.
